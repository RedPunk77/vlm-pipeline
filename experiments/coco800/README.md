# Протокол COCO800

Файлы фиксируют состав и параметры эксперимента до просмотра тестовых результатов

- `validation.jsonl` — 20 изображений для выбора политики проверки
- `test.jsonl` — 800 отдельных изображений для итоговой оценки
- `splits.json` — ID изображений, seed, исключения и хеш исходной разметки
- `labels.json` — оцениваемые классы COCO
- `protocol.json` — ревизия модели, версии библиотек, хеш исходников и критерий выбора политики

Пути в manifest рассчитаны относительно рабочей папки набора, фотографии скачиваются командой `python scripts/prepare_experiment.py --download all` в `data/coco800`

Эта папка хранит протокол, а не готовые результаты, полный отчёт появится только после обработки всех 800 изображений

Если в итоговую политику войдут детекции, отсутствующие в ответе Qwen, они отмечаются отдельным источником, дополнительно оценивается baseline только на YOLO

Это эксперимент по объектам COCO, OCR в нём не оценивается
